처음 한 번만 설정

  1. 깃허브 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름 아무거나, 기간 No expiration(또는 1년)
  4. Repository access: Only select repositories → lucky-palace
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate → 나온 토큰(github_pat_…)을 복사해서 아래에 붙여넣기
토큰은 이 폰(브라우저)에만 저장돼요. 다른 사람에게 보여주지 마세요.
